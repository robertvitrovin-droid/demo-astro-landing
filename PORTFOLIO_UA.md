# Сайт для веломайстерні (демо)

**Демо-проєкт для портфоліо.** Веломайстерня «Спиця» вигадана, на сторінці є позначка DEMO, клієнтів і відгуків немає.

**Задача.** Одна сторінка для малого бізнесу, яка швидко відкривається з телефона, пояснює послуги й ціни та веде до дзвінка чи повідомлення.

**Що зроблено.**
- Перший екран з пропозицією, послуги з цінами «від», 3 кроки роботи, FAQ, кнопки «Подзвонити» і «Telegram».
- Адаптивна верстка для мобільного й десктопа, навігація з клавіатури, видимий фокус.
- Базове SEO: title, description, canonical, Open Graph, schema.org.

**Результат.** Сторінка ~11 КБ без JavaScript у браузері. Lighthouse 100 у всіх 4 категоріях, mobile і desktop: [звіт mobile](https://robertvitrovin-droid.github.io/demo-astro-landing/lighthouse/mobile.report.html), [звіт desktop](https://robertvitrovin-droid.github.io/demo-astro-landing/lighthouse/desktop.report.html). Умови: Lighthouse 12.8.2, профіль mobile за замовчуванням і `--preset=desktop`, локальна збірка (`astro preview`), 2026-10-09. Accessibility 100 — це автоматична перевірка, а не повний аудит WCAG.

**Посилання.** [Живе демо](https://robertvitrovin-droid.github.io/demo-astro-landing/) + [GitHub](https://github.com/robertvitrovin-droid/demo-astro-landing)

Стек: Astro 5, HTML, CSS, SVG, Lighthouse · **Ціна від 3 500 грн**, від 2 днів
