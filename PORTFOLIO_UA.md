# Швидкий лендинг для малого бізнесу на Astro (демо-проєкт)

**Демо-проєкт для портфоліо.** Велосервіс «Спиця» вигаданий; на сторінці є позначка DEMO, відгуків і клієнтів немає.

**Задача.** Малому бізнесу потрібна одна сторінка, яка швидко відкривається з телефона, одразу пояснює, що і за скільки тут роблять, і веде до дзвінка чи повідомлення.

**Рішення.**
- Структура під конверсію: зрозуміла пропозиція на першому екрані, послуги з цінами «від», 3 кроки «як ми працюємо», FAQ, блок запису з кнопками «Подзвонити» і «Telegram».
- Статична збірка Astro без JavaScript у браузері, без зовнішніх шрифтів; графіка — легкий inline SVG. Уся сторінка важить близько 11 КБ.
- Адаптивна верстка (мобільний, планшет, десктоп), липке меню.
- Доступність: навігація з клавіатури, видимий фокус, достатній контраст, великі зони натискання, семантична розмітка.
- Базове SEO: title, description, canonical, Open Graph, розмітка schema.org.

**Стек.** Astro 5, HTML, CSS (без фреймворків), SVG, Lighthouse.

**Результат.** Lighthouse 100/100/100/100 на мобільному і десктопі (LCP 0.7 с на мобільному), виміряно локально. Додаються звіти та скриншоти на ширині 1440 і 390 px. Шаблон швидко адаптується під інший бізнес: тексти, кольори, секції, домен і хостинг (Netlify, Cloudflare Pages, VPS).

**Ціна від:** 3 500 грн · термін від 2 днів
